# Kely private beta

Idea → discussion → approved plan → Generate → saved post → focused revisions.

This release targets three invited accounts on free infrastructure. No payments or public registration. Build and local verification do not constitute cloud launch acceptance.

The hosted Docker image runs the web server and worker together after verifying the migration manifest. Render configuration starts with invitations and real generation disabled. Credentials, user data, provider evidence and backups must never be committed.

See docs/beta-release.md and docs/beta-launch-runbook.md. README.md and additional reports in the founder workspace describe local development history and are not part of the deployment source package.
